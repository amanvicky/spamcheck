what this is

Trained offline by a 90-line Python trainer on the UCI SMS Spam Collection (research dataset, cited in the repo). The whole model is one JSON file of log probabilities — which is why this page can run it with no server.

The same computation runs in the repo's terminal CLI and here, and a CI parity gate proves both give identical outputs on real test messages.
